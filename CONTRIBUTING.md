# Contributing

Bug reports, reproductions, and scientifically adverse results are welcome.

For a reproduction report, please include:

- commit SHA;
- operating system and Python/DIALS versions;
- public corpus identifier;
- input hashes;
- exact command;
- output JSON hash;
- whether the published decision reproduced.

Method changes should not overwrite baseline B. Put experimental changes
behind a separately named comparator, add adverse controls, and state which
corpora informed the change.
