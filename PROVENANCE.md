# Provenance and research roles

This project was developed by Evan Thomas Kotler with extensive assistance
from AI systems for code construction, test design, forensic packaging,
scientific criticism, and writing.

The collaboration produced both useful safeguards and avoidable process
overhead. The public repository therefore follows three principles:

1. Claims are tied to executable artifacts and public data, not conversational
   authority.
2. Development, prospective, excluded, and unresolved cases are labeled
   separately.
3. Negative results and pre-execution invalidations are retained.

The archived evidence packages provide a deep audit trail. This repository is
the scientific interface: concise code, public manifests, tests, results, and
a methods manuscript that can be evaluated without accepting NFC terminology.
